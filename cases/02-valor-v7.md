# The Binding Oath

*VALOR_V7 · Layered instructions*

**Status:** discontinued experiment. This account concerns the preserved 6 October 2026 snapshot.

## Intended problem

Package assistant behavior, work-package rules and supporting knowledge into a more inspectable structure.

## What existed

Separate instruction, system, knowledge, template, evaluation and documentation areas, plus manifest generation and verification tools. Evaluation scenarios cover mode changes, security boundaries, work-package lifecycle and exports. Release v7.0.0 was published on 8 December 2025.

## Limits and documented issues

A versioned package and a set of evaluation scenarios are useful evidence of organization. They do not establish reliable generative behavior, acceptance by users or fitness for regulated work. Tool presence is not a claim that those tools ran successfully during this curation.

Site-specific configuration and strong readiness claims in the source are omitted. Root and documentation license files declare Apache-2.0; third-party material still needs content-level review before reproduction.

## Why this track ended

A specific discontinuation reason is not documented in the selected repository evidence. The general owner account remains background, separate from the packaging milestones.

## What to retain

The distinction between policy structure, behavioral evaluation and integrity checks. Preserve release metadata separately from Git history; a release date should not be inferred from repository creation.
