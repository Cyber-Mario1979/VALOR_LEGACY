# The First Spark

*Valor-CQV · Advisory origins*

**Status:** discontinued experiment. This account concerns the preserved 6 October 2026 snapshot.

## Intended problem

Make CQV consultation more structured by defining an assistant role, commands and an advisory mode alongside a work-package mode.

## What existed

A small instruction repository with role and command documents, a master instruction file, export examples and PDF guide/reference material. Work-package traceability and export concepts appear alongside planned presets and linking features.

## Limits and documented issues

The preserved files establish instructions and examples, rather than a working application or evidence of accepted operational performance. The original README makes professional-readiness claims that this history does not adopt.

The README names the master instruction file differently from the actual captured filename. PDF guides and references have not been cleared for reproduction and are excluded.

## Why this track ended

No repository-specific stopping decision is documented in the selected evidence. The owner’s collection-level explanation of drift and fresh attempts should not be converted into a claim that a particular feature caused this track to stop.

## What to retain

A short explanation of the advisory/work-package distinction and the need to tie documentation to actual file identities. Original instruction and PDF bytes are excluded from this presentation.
