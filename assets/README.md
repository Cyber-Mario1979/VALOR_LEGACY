# Original visual assets

The SVGs in this folder are original presentation visuals credited to Amr Hassan. Graphite carries the page, turquoise marks the record, and peach distinguishes unresolved scope or ASBP's separate event-anchor measure. Text remains legible without animation or interaction.

- hero.svg: the opening question and a constellation of ten attempts.
- reading-map.svg: seven chapter cards and The Convergence; corresponding Markdown links supply navigation.
- timeline.svg: nine commit-date spans and a separately labeled ASBP event window, with approved display titles and an undated Owner-attributed closing destination.
- chapter-01.svg to chapter-07.svg: chapter introductions and conceptual vocabulary.
- convergence.svg: The Convergence, the Owner-attributed final destination.
- authority.svg: historical design intent, not an implemented-system diagram.
- acceptance.svg: accepted synthetic M0 beside the actual closed-unmerged PR #5 outcome and preserved branch.

No source blueprint, screenshot, external image, brand asset or cloud-generated artwork is included. Visual interpretations identify their limits beside the graphic.
