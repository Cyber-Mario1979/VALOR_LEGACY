# Five lessons worth keeping

## State: inspect what refusal changes

The recorded guard-before-mint correction shows that a refusal can give the right message after making the wrong persistent change. Preserve the CLOSED/DISCHARGED disposition while explaining the useful ordering lesson. ASBP's loaded-state checks provide a different, narrow consistency example.

## Evidence: say what was checked

A manifest establishes byte identity; a pack validator checks selected structure; tests exercise particular behavior. Those results should carry their scope and source identity.

## Authority: admission is a separate decision

PROJECT_RECORD distinguishes preserved bytes, admitted evidence, accepted decisions and mutation authority. The architecture expresses related boundaries as design intent. A count or merge event cannot collapse them.

## Scope: a smaller slice has its own meaning

PE's M0 acceptance belongs to the synthetic checkpoint. It does not accept an unmerged browser branch, external-provider AI or wider lifecycle work. ASBP's changing intent is its own dated account.

## Acceptance: keep success and limits together

The factory's refactor acceptance can remain visible beside deferred scope. Stale status wording belongs beside later events. Useful work and incomplete ambitions both deserve an accurate record.
